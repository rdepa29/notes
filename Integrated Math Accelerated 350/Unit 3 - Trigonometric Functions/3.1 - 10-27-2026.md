# Radians
- standard unit for rotation
- defined as $\frac{180\degree}{\pi}$
	- $\approx 57.3\degree$
- for a circle with radius of $x$...
	- try graphing an arc with arc length of $x$
	- you should find that to get one rotation of the circle, you need six and a little bit more arcs
	- that value is $2\pi$, and this process becomes the definition of the radian
- converting:
	- $x\degree \to \theta~rad$
		- $\theta~rad=x\degree\cdot\frac{\pi~rad}{180\degree}=\frac{x\pi~rad}{180}$
		- example: $70\degree~\to~rad$
			- $70\degree \cdot \frac{\pi~rad}{180\degree}$
			- $7\cdot \frac{\pi~rad}{18}$
			- $\frac{7\pi}{18}$
	- $\theta~rad \to x\degree$
		- $x\degree=\theta \pi~rad\cdot\frac{180\degree}{\pi~rad}=\frac{180\degree}{\theta}$
		- example: $-\frac{\pi}{2}\to x\degree$
			- $-\frac{\pi}{2}\cdot \frac{180\degree}{\pi~rad}$
			- $-\frac{1}{2}\cdot 180\degree$
			- $-90\degree$

- expresses rotation as both a value in radians and a position on the XY coordinate grid
- origin at $(0,~0)$
	- starts facing $(\infty,~0)$ at $0~rad$
	- each rotation around the circle is $2\pi~rad$
	- from there, you can get any rotation as an expression of $\pi$
		- $180\degree=\pi$
		- $90\degree=\frac{\pi}{2}$
		- $45\degree=\frac{\pi}{4}$
		- ...
- converting from rotation to position:
	- for common rotation values ($45\degree$, $90\degree$, etc.), there are special triangles set up for finding the position on the circle of those values
		- 45-45-90 for $45\degree$, $( \frac{\sqrt{ 2 }}{2}, \frac{\sqrt{ 2 }}{2})$
		- $90\degree$ is $(0,~1)$
		- $180\degree$ is $(-1,~0)$
		- ...
	- in general:
		- $(x,~y)=(\cos \theta,~ \sin \theta)$
- terms
	- coterminal angle
		- two different expressions that result in the same position
		- example: any multiple of $2\pi~rad$ results in the same position, $(r,~0)$
